# Public Release Checklist

## Current status

This repository is publicly available as a local-prototype codebase. No release has been created and no license has been selected. Use this checklist before any future release, deployment, or scope expansion.

## Before public sharing

- [ ] Perform a human review of every tracked file for credentials, private data, and proprietary material.
- [ ] Confirm `.env.local`, database files, logs, virtual environments, build output, and dependency directories remain ignored.
- [ ] Review any screenshots and examples for sensitive content.
- [ ] Confirm all public claims describe XOD as a working local prototype, not a production-ready system.
- [ ] Confirm no document presents engineering tests as scientific or external validation.
- [ ] Decide on a license deliberately; no license is selected yet.
- [ ] Decide whether an initial commit and public remote are desired; neither exists yet.
- [ ] Re-run the documented backend tests, frontend regression tests, typecheck, and production build in the intended release environment.
- [ ] Review third-party dependencies and provider terms for the intended use.
- [ ] Define a responsible disclosure contact before inviting external contributors.

## Claims review

Before publication, check that the following are always qualified:

- Research Integrity Agent: **PROPOSED / CATALYST-SCOPED WORK**.
- Zotero integration: **PROPOSED**.
- Specialist readiness: implemented; specialist-agent execution: not implemented.
- Graph visualization, autonomous confidence changes, external benchmark validation, production deployment, and paying-user validation: not implemented.
- XOD cannot guarantee research integrity, accuracy, safety, or trustworthy AI.

## Publication gate

The appropriate status after this stage is **ready for human review before publication**, not ready to publish automatically.
